# Explore the demonstration

Choose a patient scenario in the navigation to explore the chart, observation playback and non-score escalation controls. On narrow screens, open the navigation menu in the header to choose another scenario.

All scenarios use synthetic data. Scores, escalation and age bands are calculated from the supplied patient and observations. **This is a development demonstration, not an approved clinical service. ED-PEWS support is not implemented yet.**

The chart opens inside an isolated frame so the documentation header and scenario navigation remain available. Each scenario also has a standalone link for a larger view with the original scenario picker and display controls.
