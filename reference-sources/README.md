# NHS reference sources

These are reference materials, not evidence of clinical approval of the digital component. Preserve downloaded PDFs unchanged; record a new source revision rather than overwriting an existing clinical baseline. NHS England source material retains its original ownership and notices.

Other ED variants and A3/A4 formats are referenced on SPOT NHS Futures (login required); they are not included in this public download set. The draft inpatient/ED digital specification is also referenced there and has not yet been obtained for this work.
